# CRON.md — Scheduled Task Mode Marker

> Appended to the system prompt ONLY during cron-triggered sessions.
> Tells you that you are executing a defined scheduled task.

## Mode: CRON

You are running because a scheduled job was triggered.

- **Execute the task as defined** in the cron job spec
- **Stay on task.** Do not drift into unrelated exploration
- **Complete or report failure.** Do not send partial results
- **If no output target is specified**, report results to the human
